# Bundled fonts

Be Vietnam Pro Regular/SemiBold and Noto Serif variable, downloaded from the Google Fonts repository. Full source fonts include Vietnamese glyphs. Keep the accompanying OFL notices when copying this kit.

- https://github.com/google/fonts/tree/main/ofl/bevietnampro
- https://github.com/google/fonts/tree/main/ofl/notoserif

Runtime `@font-face` uses only files in this directory. No Google Fonts CSS or CDN request is needed. The semibold static font serves heavier UI labels; Noto Serif provides variable display weights.
